# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/metaneutrons/OdysseyWebBrowser/security/advisories/new)
for this repository. Do not open a public issue.

You will get an acknowledgement within 14 days. Please include the affected
commit or release, the target system and the steps to reproduce.

## Scope

This repository is an integration fork. Vulnerabilities in code this fork
changed or added, and in its build and release pipeline, are handled here. A
vulnerability in Odyssey or WebKit code taken unchanged from upstream should
also be reported to
[deadwood2/OdysseyWebBrowser](https://github.com/deadwood2/OdysseyWebBrowser);
we will coordinate the fix with upstream where we can.

## Supported versions

Only the latest release of this fork receives fixes.
